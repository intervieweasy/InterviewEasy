# Interview platform repositioning

## Goal
Replace the corporate-training and individual-learning presentation with a practical interview workspace for scheduling, running, and managing technical interviews.

## Changes
- Update the shared header with separate **Practice**, **Pricing**, **Demo**, **Careers**, and **Contact** links, plus a clear **Schedule interview** action.
- Rework the home page around the actual interview flow: schedule a session, invite candidates, conduct video interviews, ask structured questions, write and run code, execute automated unit tests, score candidates, and review results.
- Replace the current “Get started” track cards and onboarding workflow with an interactive-looking interview workspace preview and a concise hiring workflow.
- Keep the technology question menu, topic pages, video carousel, logo, favicon, Careers page, and Contact page.
- Create dedicated Practice, Pricing, and Demo pages so every main menu item opens a real page.
- Remove remaining corporate-training and individual-plan wording from the home and contact pages.
- Give every new page unique titles, descriptions, social metadata, and keywords.

## Page direction
- **Practice:** role and technology practice sets, coding questions, code editor preview, and automatic test-result states.
- **Pricing:** clear plans for interviewers and hiring teams, without the old corporate/individual split.
- **Demo:** a guided product tour showing scheduling, video, code execution, unit tests, scorecards, and interview reports.

## Verification
Check desktop and mobile layouts, all navigation destinations, page metadata, and the preview build.
